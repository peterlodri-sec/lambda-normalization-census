> - 🦀 **[crabcc](https://github.com/crabcc-labs/crabcc)** — a fast Rust **symbol-index & call-graph engine for AI coding agents** (CLI + MCP). Sub-second `sym`/`callers`/`refs`/`graph` + RAG + memory across JS, TS, Ruby, Python, Rust, **and now C / Zig / YAML**. It indexed the **Linux LTS kernel (6.18) — ≈3.9M symbols — in under 3 minutes**.
> - 🧪 **Vaked** — a **research OS for agent systems**: a *flake-native capability-graph language* where you **declare** an agent system once and compile it to Nix flakes / NixOS modules / Zig daemons / eBPF policy / OpenTelemetry / crabcc indexes / docs. Runtime on OTP + Zig; HCP/Litany protocol. *(It uses crabcc for indexing — the tools compound.)*
> - 🧮 **[λ-Normalization Census](https://github.com/peterlodri-sec/lambda-normalization-census)** — open datasets + reproducible engines for real CS research (the Barendregt–Geuvers–Klop conjecture; normalization densities). *Computed, not asserted* — e.g. the smallest closed WN-but-not-SN λ-term is **natural size 13** (counts = [OEIS A275057](https://oeis.org/A275057)).
