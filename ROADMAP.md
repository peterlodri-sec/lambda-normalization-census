# Roadmap

Research-driven; contributions and sponsor-submitted experiments shape it.

## Near term
- [ ] Shrink the **undecided tail**: stronger SN/WN deciders (perpetual-reduction bounds, type-based shortcuts) to push the decidable frontier past n=16 exact / n=55 MC.
- [ ] Add the **variables-cost-0 size model** (David et al. 2013) for a side-by-side density comparison with the natural-size (A275057) model.
- [ ] Tighten Monte-Carlo CIs (larger K) and extend the separator-density curve.

## Medium term
- [ ] Typed restrictions (simply-typed / System F fragments) and their separator behavior.
- [ ] Alternative size conventions (Tromp binary-λ); cross-model dataset in one place.
- [ ] A small DOI release (Zenodo) of the dataset.

## How to influence it
Open an issue, start a discussion, or — as a [sponsor](https://github.com/sponsors/peterlodri-sec) — submit an experiment we run and publish. See [CONTRIBUTING](CONTRIBUTING.md).
